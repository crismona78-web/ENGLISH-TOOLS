# Word Match

A matching and gap-fill game to practise B2 English. Single static file, no build step, no dependencies.

- **Vocabulary units 1-10:** pair English words with their Spanish translation, 10 per round, one unit or a mix of units. Played words are remembered (localStorage), so new rounds show new words. Every round ends with a recap that shows each word in an example sentence.
- **Exam skills:** phrasal verbs and idioms (Pairs and Gap Fill / Idiom Detective) and dependent prepositions (Gap Fill).
- **Grammar:** 15 topics with explanations: used to / be used to / get used to, wish and if only, passive, conditionals, reported speech, relative clauses, gerund or infinitive, modal verbs, past tenses, linking words, would rather / had better, have something done, comparatives, collocations, articles and quantifiers.

No timers: each quiz has 10 questions and a Next button after every answer.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Push `index.html` and this README to a repository.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. The game will be at `https://<user>.github.io/<repo>/`.

Fonts (Bricolage Grotesque, Figtree) load from Google Fonts; the game still works offline with fallback fonts.
